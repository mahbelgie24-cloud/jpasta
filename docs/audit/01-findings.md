## ج. ما تم التحقق منه يدوياً دون ملاحظات حرجة

- كل Server Action يقيّد الوصول عبر `requireOwner/requireStaff` أو `getSessionUser`
  قبل أي قراءة/كتابة حساسة (تم تتبع كل ملف في `app/actions`).
- كل صفحة `/console` تتحقق من الجلسة، وصفحات المالك تتحقق من الدور.
- لا أسرار متتبعة في git (`git grep` لأنماط المفاتيح)؛ `.env.local` و`.dev.vars`
  مستبعدان. يوجد dump محلي قديم في `backups/` (مستبعد من git).
- زود Drizzle/parameterized في كل الاستعلامات؛ لا `sql.raw` بمدخل مستخدم.
- JSON-LD يمر عبر `serializeJsonLd` (لا `</script>`).
- رفع الصور: magic bytes + نوع مخزّن من البصمة + حد 8MB + مفتاح مولّد.
- الترويسات الحية: CSP غير-متزامن على المسارات الديناميكية، SRI/ثابت على
  الثابتة، HSTS في الإنتاج، `nosniff`، `DENY`، `no-referrer` للكونسول/الطلب.
- `npm audit --omit=dev` = 0.
